# COVID-19 Mobility Analysis

## Project Overview

This project analyses and visualises changes in mobility patterns in the United Kingdom during the COVID-19 pandemic using Python and Google Community Mobility data.

The analysis focuses on how mobility changed across different categories, particularly around the introduction of the first UK national lockdown on 23 March 2020.

## Objectives

- Explore and prepare UK COVID-19 mobility data.
- Analyse changes in mobility over time.
- Compare mobility patterns before and during lockdown.
- Visualise changes across key mobility categories.
- Demonstrate practical data analysis and visualisation skills using Python.

## Dataset

The analysis uses Google Community Mobility data for the United Kingdom.

The dataset includes mobility measures for:

- Retail and recreation
- Grocery and pharmacy
- Parks
- Transit stations
- Workplaces
- Residential areas

Mobility is measured as the percentage change from a baseline period.
